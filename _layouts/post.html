--- layout: default css: post --- {%- comment -%} Daily Info article layout. Chains to default.html. IMPORTANT: every post must set `css: post` in its OWN front matter, same as this layout does -- Jekyll does not cascade a layout's front matter down to the pages using it, so this file's `css: post` above only covers a page with no `css:` of its own (in practice, none: every post needs pages/post.css). See app.html's header comment for how this was found (post.css silently never loaded on the first real post). Required front matter (STATUS.md section 4): title, description, css (must be "post"), heading, category (a name in _data/categories.yml, which gives the page its colour and default glyph), date, updated, read_min, slug (must match the filename). Body is markdown prose, one "## " heading per section. Optional: image (a real editorial photo -- never an app's store icon), glyph (overrides the topic's glyph on the drawn banner), steps (true: the sections are numbered steps), takeaways (2-4 one-line summary points, each restating something the article itself says), faqs, related (other posts' `slug` values). A closing note goes in
at the end. The body is split on its H2s so each section renders as its own card, and the same split builds the "On this page" contents -- no heading list is written twice. kramdown gives every H2 an id.
