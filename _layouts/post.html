See app.html's header comment for how this was found (post.css silently never loaded on the first real post). Required front matter (STATUS.md section 4): title, description, css (must be "post"), heading, category (a name in _data/categories.yml, which gives the page its colour and default glyph), date, updated, read_min, slug (must match the filename). Body is markdown prose, one "## " heading per section. Optional: image (a real editorial photo -- never an app's store icon), glyph (overrides the topic's glyph on the drawn banner), steps (true: the sections are numbered steps), takeaways (2-4 one-line summary points, each restating something the article itself says), faqs, related (other posts' `slug` values). A closing note goes in
at the end.
