--- layout: default css: app --- {%- comment -%} App landing page layout. Chains to default.html. IMPORTANT: this file's own `css: app` above only affects a page that has no `css:` of its own -- Jekyll does NOT cascade a layout's front matter down to the pages that use it. Every page on this layout must still set `css: app` itself (as cloud-storage-backup-drive.html does), or it renders with shell.css only and no pages/app.css. Confirmed the hard way: post.html originally relied on exactly this false cascade and pages/post.css silently never loaded. Fully front-matter-driven, no body content -- the same reasoning fixmypcperth uses for suburb.html: with four apps now sharing this one layout (section 5a), letting any of them carry hand-written body prose is exactly how near-duplicate doorway pages happen. Required front matter (STATUS.md section 4): title, description, css (must be "app"), app_name, tagline, icon, ios_url and/or android_url, category, features (icon, title, text), how_it_works (3x {title, text}), faqs (q, a).
