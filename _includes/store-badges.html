{%- comment -%} Store badges: Apple + Google Play, real SVG marks (not text buttons). Params: ios_url, android_url -- either or both; only what's passed renders. Optional class= adds a class to the wrapping .store-badges div. Optional app= (an app's name) goes into each badge's accessible name ("Get Document Reader on Google Play"), for pages that show several apps' badges, where identical link names would be ambiguous. Usage: {% include store-badges.html ios_url=app.ios_url android_url=app.android_url %} Icon paths are the same Apple-glyph / Google-Play-triangle renditions widely used on app sites' badges -- a proven, recognisable pattern, not a fresh guess at official brand assets (Apple/Google's own badge files carry usage guidelines this avoids needing to follow exactly, while still reading as the real thing). {%- endcomment -%}
