{%- comment -%} Shared icon sprite: a hidden SVG holding defs, referenced elsewhere as . One request, one cache entry, instead of repeating full path data per icon per use. Included once in default.html, right after opens. One drawing spec for every icon, so they sit together at any size: - 24x24 grid, drawn inside a 2-unit margin (3-21 for round and square shapes, so circles and squares look the same size). - 1.75 stroke, round caps and joins, no fills. One exception: the bare tick (i-tick) is 2.5, because it only appears small, inside a filled badge, where i-check's own circle would draw a ring in a ring. - 2-unit corner radius on rectangles (2.75 on the phone, 5.25 on the toggle's pill). - Arrowheads sit exactly on the ends of their arcs (the arcs and the cloud's lobes were computed, not eyeballed). Each icon names one thing; pick the one that matches the label beside it rather than the nearest-looking one. Set an icon by name in front matter (e.g. `icon: cloud`); app.html looks up #i- here. {%- endcomment -%}
