{%- comment -%} Decorative gradient-mesh glow for a hero section. Pure atmosphere: sits behind the content (z-index below it), aria-hidden, pointer-events:none. Uses --brand/--brand-2/--accent (sampled from the real logo, see STATUS.md 4e). Three plain divs with CSS radial-gradient backgrounds, drifting via transform. This replaced an SVG version (blurred circles under an feGaussianBlur filter) in step 5: SVG filters aren't GPU-composited, so that blur was re-rasterised on the CPU every frame of the drift and held the page to ~12fps in testing (61fps without it). Radial gradients are already soft-edged, so the blur added little but cost. Styles live in shell.css ("Hero glow"). The drift is ~18s+ per cycle -- well clear of the ~5s (0.2Hz) range Apple's own motion guidance flags as uncomfortable -- and freezes under prefers-reduced-motion rather than just slowing down. Usage: {% include hero-glow.html %} as the first child of a position:relative container; pair with .hero-glow-host on that container and .hero-glow-content on the real content (shell.css). {%- endcomment -%}
